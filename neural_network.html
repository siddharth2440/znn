6. Step 4 — Loss (MSE)

Exactly as implemented in loss.zig — Mean Squared Error.

MSE Formula (loss.zig:16-22)

L = (1/n) · Σi (ŷi − yi)²   // n = number of output neurons = 1

// Derivative (also in loss.zig: derivative() )
∂L/∂ŷ = (2/n) · (ŷ - y)
LOSS

L = ( 3.755 − 10.0 )² / 1
L = ( -6.245 )²
L = 39.00
Interpretation: A loss of 39 is large. Because every z in this network is positive (ReLU active everywhere), the loss gradient flows cleanly back through every layer with zero attenuation — ideal for seeing the full backpropagation mechanics.

7. How Every Derivative Is Computed

Backpropagation never invents numbers — it multiplies three known partial derivatives via the chain rule. This section shows exactly how each factor is obtained, including the activation-function derivative for every layer you cross.

Forward
Loss
Derivative Calculus

The Chain Rule: one product of three factors

∂L/∂w = ∂L/∂anext  ×  ∂anext/∂z  ×  ∂z/∂w

// factor 1: how much the LOSS changes as the activation changes
// factor 2: how much the ACTIVATION changes as its pre-activation z changes <- the activation-function derivative
// factor 3: how much the pre-activation z changes as THIS weight changes

Factor 1 — Derivative of the loss

From loss.zig:41-43, the MSE derivative (it is why derivative() writes 2.0/n × (prediction - target)):

∂L/∂ŷ = (2/n) · (ŷ - y)   // n = 1 output neuron. First compute the error, then scale by 2:
(ŷ - y) = 3.755 - 10.0 = -6.245
∂L/∂ŷ = 2 × (-6.245) = -12.49

// why 2? because d/dŷ [ (ŷ-y)² ] = 2(ŷ-y). The ×1/n is the “mean” part of MSE.

Factor 2 — Derivative of the activation function

The network applies the same activation to every layer output (layer.zig:48: activations.apply_activation_function(.relu)). The derivative factor changes depending on which activation you use — all the ones available in matrix.zig:ActivationType:

Activationa = f(z)∂a/∂z (derivative)Value here
nonez11
relu (used)max(0, z)1 if z > 0, else 01 — every neuron active
leaky_reluz if z>0, else 0.01·z1 if z > 0, else 0.011
sigmoid1/(1 + e-z)a · (1 − a)— (always < 1)
tanh(ez − e-z)/(ez + e-z)1 − a²— (always < 1)
This is the activation step at every layer crossing (including the Layer-2 ↔ Layer-3 boundary): when a signal moves from one layer's activations into the next layer's pre-activation z, it passes through that gate. With ReLU the gate multiplies by 1 for every active neuron, so the error crosses at full strength. With sigmoid/tanh the gate multiplies by a number < 1, and multiplying by < 1 again and again across layers shrinks gradients exponentially — the vanishing-gradient problem.

Factor 3 — Derivative of the weighted sum

zi = Σj wij · aj(prev) + bi

∂zi/∂wij = aj(prev)   // d/dw of a weighted sum = the input that weight was multiplied by
∂zi/∂bi = 1       // the bias always contributes with slope 1

Putting the three factors together

Example A — w1,1(3): just one layer away from the loss

∂L/∂w1,1(3) = ∂L/∂ŷ  ×  ∂ŷ/∂zout  ×  ∂zout/∂w1,1(3)
      = (-12.49)  ×  (ReLU′ = 1)  ×  (ah4(2) = 2.02)
      = -12.49 × 2.02 = -25.2298    ✓ exactly Step 5's value

Example B — w1,1(1): the deepest weight, crossing BOTH hidden layers

This weight sits all the way back at the input. The error reaches it by accumulating through every neuron in the next layer (the sum of four parallel paths through h₄…h₇), then through the activation gates and linear parts at every crossing:

∂L/∂w1,1(1) = [ Σi ∂L/∂zi(2) · ∂zi(2)/∂ah1  ]  ×  ∂ah1/∂zh1  ×  ∂zh1/∂w1,1(1)

// the sum over the 4 neurons of layer 2: (their error) × (their weight from h₁)
  = [ (-7.494×0.40) via h₄ + (-4.996×0.30) via h₅ + (-6.245×0.50) via h₆ + (-3.747×0.20) via h₇ ]
        × (ReLU′ at h₁ = 1)  ×  (its raw input x₁ = 2.0)
  = [ -2.9976 + -1.4988 + -3.1225 + -0.7494 ] × 1 × 2.0
  = ( -8.3683 )  ×  2.0 = -16.7366    ✓ exactly Step 7's value

The bracket is the exact mechanism of "spreading blame": the error that started as −12.49 at the output gets distributed to h₁ via the four paths above, totals −8.3683, passes the ReLU gate unchanged, and finally hits the weight with slope equal to its input (2.0).

What happens if a neuron is "dead"?

If any neuron had z ≤ 0, its ReLU′ = 0, so the entire chain-rule branch through it becomes zero — no gradient reaches that neuron's weights, and it stays frozen until other weights change its z back above zero. This "dying ReLU" behaviour follows directly from the derivative table above.

The Chain Rule — the engine of backprop

∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂zout × ∂zout/∂w

Component 1: ∂L/∂ŷ = 2(ŷ − y)/n  (MSE derivative, loss.zig:42)

13. Verification — Loss Goes Down

Feed the updated parameters forward again and watch the loss shrink.

REDO Forward pass with updated weights:

a(1)new = ReLU( W(1)new · x ) = [2.7715, 3.2463, 3.0668]
a(2)new = ReLU( W(2)new · a(1)new ) = [4.6204, 3.9718, 4.7121, 4.7181]
ŷnew = W(3)new · a(2)new = 13.0409

Lold = (3.755 − 10)² = 39.00
Lnew = (13.0409 − 10)² = 9.25   ✓ Loss decreased 39.0 → 9.2

What just happened?

Our prediction was too low (3.76 vs 10.0), so the loss's error signal at the output was negative. All gradients turned out negative, and gradient descent increased every weight — exactly the direction that lifts the prediction toward the target. One epoch moved the loss from 39.0 down to 9.25, a 76% reduction.

Running many epochs would keep nudging parameters until ŷ ≈ 10.0 and the MSE approaches zero.

14. Intuition & Key Takeaways

Forward Propagation

  • Signals flow left → right: input → hidden → output.
  • Each neuron: z = W·a + b, then a = activation(z).
  • In this code: matrix_multiplication → matrix_addition → apply_activation_function(.relu) (layer.zig:34-58).
  • ReLU keeps activations positive, avoiding the gradient decay of sigmoid/tanh.

Backward Propagation

  • Signals flow right → left using the chain rule.
  • Each parameter's gradient = (error signal of its neuron) × (its activation/input).
  • Error signals accumulate through the transposed weight matrix (WT).
  • ReLU′ = 1 for active neurons lets signals pass unattenuated; a dead ReLU (z ≤ 0) blocks its gradient entirely.

Gradient Descent

  • Optimum: θ = θ − η · ∂L/∂θ.
  • Negative gradient → weight increases (prediction too low).
  • Positive gradient → weight decreases (prediction too high).
  • η too large → divergence (try it: η=0.5 with our gradients almost doubles every weight!).

Dimension Flow

  • 2 inputs · W(1) is 3×2 → 3 neurons
  • 3 → W(2) (4×3) → 4 neurons
  • 4 → W(3) (1×4) → 1 output
  • Gradient matrices mirror weight matrices exactly, so updates are element-wise.

Why does the code print matrices differently from this page?

In matrix.zig, Matrix.init(cols, rows) stores data row-major as (rows × cols), and layers are built with init(input_size, output_size). So on this page we describe W(1) as a 3×2 matrix (3 output neurons × 2 inputs) — the same numbers, just written rows = neurons of the receiving layer.
